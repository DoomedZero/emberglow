# Emberglow

**Emberglow** is a cozy, top-down pixel-art camping game prototype made with the Godot Engine. Explore a small forest base camp, collect sticks, and use them to light the campfire.

> **Status:** Early playable prototype — features and content are still in development.

## Current Features

- Top-down player movement with directional animations
- Pixel-art forest environment with ground tiles, trails, grass decoration, and tree boundaries
- Tree collisions and Y-sorted character/world-object rendering
- Stick pickups using the **E** interaction key
- A stick counter in the HUD
- A campfire that consumes **5 sticks** when lit
- A separate flame sprite that appears after the campfire is lit
- Background music

## Controls

| Input | Action |
| --- | --- |
| Arrow keys | Move |
| E | Collect a nearby stick or interact with the campfire |

When multiple interactable objects are nearby, the game targets the closest one.
